# 日记实现前需求规格 V2

更新日期：2026-10-05。

本轮只确定产品设计并记录需求，未修改应用程序。此前的日记试验代码并不等于本规格已实现。
「已确定」来自用户明确要求；「建议方案」用于补齐尚未指定的逻辑，实施前可继续调整。
本规格替代 REQUIREMENTS_CURRENT.md 中尚未补齐的设置清单及旧「补上小路」入口名称。

最新收纳箱与期限规则以 `DIARY_INBOX_RETENTION_V5.md` 为准：草稿、撤回、单片段删除、取消整条小路均进入收纳箱；回收站严格只收整篇日记。默认永久保留，可由用户主动选择保留天数。

## 1. 日记内容与首页（已确定）

一份日记对应一天，包含两部分：
- 经历小路：按时间排列的随记片段。
- 日记正文：今日结语和右上角日记按钮打开的同一份正文。

片段是一个小型富文本日记，可以同时包含文字、图片、语音、文件、多个段落，保留原有内容顺序；不能按素材类型拆成彼此无关的记录。

首页顶端每天固定出现「今日小路」「今日结语」两个入口，不要求先保存内容。当天也可以从小路右上角打开正文，两个正文入口保持同步。
跨日后，历史列表只展示一条当天日记，新一天再次提供两个入口。归档是展示规则变化，不复制或搬移正文。

| 当天结束后的内容 | 历史展示 |
| --- | --- |
| 有小路片段，正文有或没有内容 | 小路页面，右上角日记按钮访问或新建正文 |
| 无小路片段，有正文，且未显式启用小路 | 直接打开文本日记 |
| 无片段、无正文 | 不生成空白历史条目 |
| 曾显式启用小路，片段全部为空，正文有内容 | 保留小路页面，不能自动关闭 |

支持过去日期补记，允许只有小路或只有正文。只有小路时点击右上角日记按钮，直接进入可编辑的空正文页面。

## 2. 小路启用、取消与回收站

### 已确定

旧版文本日记保持直接打开文本的行为，不自动升级为小路。
历史日记设置提供复选框「显示‘经历小路’」：
- 文本日记默认不勾选；勾选后切换到小路，原正文保留，并通过右上角日记按钮打开。
- 已有小路时默认勾选。
- 手动启用后不因片段为空或删除全部片段自动取消。
- 默认今日入口存在，不等于用户显式启用了小路。

取消勾选时需弹出确认，提示整条小路移入收纳箱、正文保留。用户已撤回默认7天，改为默认永久保存，也可主动设置期限，提示显示当前实际保留策略。

必须区分「小路已启用」和「小路有多少片段」。

### 建议方案

- 弹窗按钮为「保留小路」「移入收纳箱」。确认前勾选状态和内容不变。
- 清除的是小路部分，日记正文保留；确认后切回文本页面。
- 整条小路作为收纳箱内一个完整项目，包含片段、素材、背景与排布，默认永久保留；背景素材不能因移入收纳箱立即删除。
- 恢复后重新启用小路，并恢复原片段及对应设置；不覆盖该日正文。
- 若删除后重新创建了小路，恢复时合并片段，按时间排序并去重，保留当前背景及排布，避免覆盖新记录。界面明确说明“合并到现有小路”。
- 移入收纳箱后若正文也为空，这一天从历史列表消失，但总收纳箱仍能找到该日的完整小路项目。
- 完全空白日期不生成历史条目，显式启用状态仍需保存，后来补记时可恢复这个选择。
- 自动今日入口在第一次保存有效片段时建立持续启用状态；只打开入口或选择背景不自动建立历史小路。

## 3. 背景与卡片（已确定）

道路为视觉主体，宽阔、自然蜿蜒。片段不固定在弯口，按时间从上到下排列；卡片尺寸沿用已认可效果图，高度随内容变化，保持舒适间距。
四季景物保持浅色、柔和水彩/轻漫画感觉，避免密集碎光与尖锐树影。
夏蹊采用夏日V4：保留V2草丛，只柔化树根，撤回V3的草地变疏调整。

| 名称 | 内容 | 当前素材 |
| --- | --- | --- |
| 春径 | 开花灌木，少量蜜蜂、小鸟 | seasons/chun-jing-v1.png |
| 夏蹊 | 绿树、小草、石头，树根平缓 | seasons/xia-qi-v1.png |
| 秋陌 | 金色稻田、伸到路沿的稻穗、稻草人 | seasons/qiu-mo-v1.png |
| 冬途 | 雪后小路、积雪灌木、疏落树木、柔和冬日光 | seasons/dong-tu-v1.png |

图片是静态背景；当前没有要求蜜蜂动画、鸟鸣音效或按季节自动更换。
四季素材并未验证可无缝拼接，长小路的延展与接缝需在实现时实际检查，不能粗暴拉长图片。

## 4. 背景选择页面

### 已确定

「更换背景」独立于「选择排布方式」，点击进入背景选择页面。
每个分类放在一个独立框中，框内图片可左右滑动，右上角有“>”进入该类的独立页面。
第一个框是「本机导入」。分类框最多预览8张，更多图片进入独立分类页查看。
四季背景按「春径、夏蹊、秋陌、冬途」顺序排列。

### 建议方案

- 首期只有「本机导入」「四季」两个分类，不编造额外内置类别。
- 各分类以标题、右上角“>”、横向图片缩略图及图片名组成；已选背景有蓝色选中标识。
- 「本机导入」未导入时显示导入入口；已经导入后仍保留入口。导入按钮不占8张图片的名额。
- 分类框显示前8张，独立分类页用网格展示全部图片；「本机导入」分类页也提供新增导入。
- 点缩略图可预览，点「使用背景」应用；返回而未确认不改变当前背景。
- 导入图片保存应用内副本，背景库供不同日期复用；对某天的背景选择按日期保存。
- 建议今日入口的背景与排布选择同时作为未来新一天的默认；修改历史某天只影响那一天。
- 不随系统日期自动切换四季，以用户选择为准。

当前消息没有附上新的参考UI图片，以上依据用户文字描述确定结构；精确间距、框体样式和图形细节仍可结合后续参考图调整。

## 5. 排布选择页面

### 已确定

三项单选：
1. 左右交错，默认左侧开始。
2. 全在左侧。
3. 全在右侧。

每项为小圆圈单选按钮，选中后填充蓝色。同一时间只选一项。
左右交错仅改变卡片横向位置，不改变时间顺序；删除片段后按剩余顺序重新交错。
单侧模式仍保留原卡片宽度，不自动铺满整个屏幕。

### 建议方案

选择后预览排布，点击「完成」保存，返回未确认则保持原排布。设置范围与背景一致。

## 6. 不同入口的设置

| 页面/入口 | 已确定设置 | 建议或仍需明确的部分 |
| --- | --- | --- |
| 今日小路 | 更换背景、选择排布方式 | 不显示历史小路清除开关；当天导出统一从首页进入 |
| 今日结语 | 用户尚未指定完整清单 | 建议不显示小路背景、排布和清除开关；保留现有正文编辑相关设置，当天导出统一从首页进入 |
| 历史某一天 | 显示“经历小路”、更换背景、选择排布方式、导出 | 没启用小路时隐藏背景和排布；勾选后再显示 |
| 日记首页 | 设置中的导出入口 | 点击进入日期多选，确认后统一设置内容和格式 |

历史日记的设置属于整天，正文页与小路页共享同一天设置；不能因入口不同生成两份正文或两套互不关联的配置。
今日结语的完整菜单尚未明确，表中建议不能当作用户已确认清单。

## 7. 导出设计

### 已确定

- 最终导出为一个ZIP压缩包。
- 用复选框独立选择「小路」「日记」，对应ZIP内的road和diary文件夹，至少选一项。
- 一个片段可同时有文字、图片、语音、文件；导出必须保留它们属于同一片段的关系。
- 历史单日设置可以导出当天。
- 首页设置的导出先进入多选，再让用户选择导出内容和方式。

### 建议格式

ZIP是统一包装，下面的格式是包内内容的阅读形式，不是互斥的媒体导出类型：

| 单选格式 | 文本 | 图片、语音、文件 | 使用方式 |
| --- | --- | --- | --- |
| 网页HTML，默认 | index.html，保留段落、片段时间及结构 | 媒体原文件随包保存，HTML使用相对路径展示图片、提供音频播放及文件链接 | 解压后打开阅读；音频格式不受浏览器支持时仍可打开原文件 |
| Markdown | index.md，按片段时间分节 | 图片链接、语音及文件链接，原文件随包保存 | 适合继续编辑、搬到笔记软件 |
| 纯文本TXT | index.txt，保留文字、时间与素材清单 | 素材仍保存原文件，TXT写出对应名称及相对路径 | 适合文字提取，不保留原富文本排版 |

三种格式默认都带上选中内容实际使用的媒体，不额外做“仅文字/仅语音”的拆分筛选。
不要将录音自动转写为文字，也不要把文字与语音错误导出成不同片段。
网页导出以方便阅读为主，不要求精确复刻应用的小路交互或背景动画；小路背景与排布信息随包保留，HTML可使用背景但必须优先保证文字清晰。
Markdown/TXT不显示道路背景，仍保留对应背景文件与设置记录。
导出不是承诺完整恢复应用状态的备份功能；保留内容结构信息，为关联媒体提供清楚的对应关系。

### ZIP结构建议

单日与多日使用相同目录规则，按日期分开。只建立选中且有实际内容的部分。

```text
时笺日记_2026-10-05.zip
├─ index.html                  多日/单日内容导航
├─ manifest.json               日期、片段、媒体及排布对应关系
├─ road/
│  └─ 2026-10-05/
│     ├─ index.html            小路片段按时间排列
│     ├─ background.png        所选背景，扩展名按原格式
│     └─ media/
│        ├─ 001_photo.jpg
│        ├─ 002_audio.m4a
│        └─ 003_attachment.pdf
└─ diary/
   └─ 2026-10-05/
      ├─ index.html            当天完整正文
      └─ media/
         └─ ...
```

选择Markdown/TXT时，日期下的index.html分别替换为index.md/index.txt；顶部导航列出内容文件链接。媒体保存现有原始格式，不强制转成示例中的扩展名。
片段内容以记录顺序保留，图片和语音出现在原来的相邻位置；文件名避免重名覆盖。
仅选小路不创建diary，反之亦然；只打开过但没有内容的空正文不输出占位文档。
已启用但没有片段的小路在导出面板标为「暂无片段」，不作为有内容的小路导出。附件也算内容，不能只按文本是否为空判断。
标签、日期、片段时间等必要信息随内容保存。关联到其他笔记的内容保留关联标题；不自动带出未选择的其他笔记。
多日包可命名为「时笺日记_2026-10-01至2026-10-05_共5天.zip」。

## 8. 单日与首页多选流程

### 单日

历史日记设置 → 导出面板 → 选择小路/日记 → 单选阅读格式 → 确认导出 → 选择保存位置 → 生成ZIP。

只有一种实际内容时，默认勾选可用项，另一项禁用并说明没有内容。两种都有时默认都勾选。
没有任何可导出内容时不能生成空包。

### 多选

首页设置 → 导出 → 首页进入日期多选 → 勾选日期/全选 → 下一步 → 同一个导出面板 → 内容和格式统一选择 → 保存ZIP。

多选期间显示「已选择N天」；底部提供「取消」「下一步」。
导出面板显示实际数量，例如：
- 已选择12天。
- 小路：8天有内容。
- 日记：10天有内容。

格式一次选择，应用到所有选中日期，首期不提供逐日不同格式。
没有所选部分的日期自动跳过，在面板明确显示「将导出N天，另M天没有所选内容」；不默默创建空文件夹或错误声称全部日期都有导出。
若某一项在所有选中日期里都无内容，则禁用该复选框；若实际结果为0天则禁用导出按钮。
返回上一步保留已选日期；打开导出面板不会丢失多选状态。
今日两个入口不作为两份可勾选记录：首页导出时，如今天有内容，以日期提供一个「今天」选项。
导出失败保留日期和设置以便重试，成功后展示保存位置。

## 9. 后续实施检查重点

- 旧文本日记直接打开、显式启用空小路、删除最后片段后的模式保持。
- 今日两个入口同步；跨日后无内容日期不生成条目。
- 取消小路只回收小路，不删除正文；取消弹窗不改变数据；恢复不覆盖新内容。
- 收纳箱/回收保存期间完整保留片段媒体、自定义背景及对应设置，期限以用户主动选择为准，默认永久。
- 分类最多8张预览，进入独立页可查看全部；导入背景跨重启仍可用。
- 三种排布保持时间顺序，卡片不绑定背景弯口；长列表没有明显背景接缝或图片拉伸。
- 混合文字、图片、语音、文件的片段导出保持原顺序；ZIP解压后相对链接可用。
- 单日、跨日期多选、只有小路、只有正文、部分所选日期无对应内容的导出结果一致。
