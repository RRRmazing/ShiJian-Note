# 时笺

**安排事务，整理待办，记录生活，收藏记忆。**

本地保存 · 无需账号 · Android 8.0 及以上

[功能介绍](#功能介绍) · [开始使用](#开始使用) · [导出与备份](#导出与备份) · [开发与构建](#开发与构建)

</div>

时笺是一个本地优先的 Android 时间管理与记录应用。你可以用时间表安排有日期的事务，用待办整理清单和当天计划，用日记留下每天的记录，用记忆分类收纳资料与想法。

界面采用简约的浅色卡片设计，包含时间表、待办、日记、记忆和设置五个模块。日常记录无需登录或联网，文字和时笺保存的素材留在设备本地。

## 功能介绍

### 时间表：把有日期的事务安排好

- 创建事务时填写名称、日期、可选的具体时分和详情，也可设置准时或提前提醒。
- 按日期分组展示；点击卡片展开详情与编辑、归档操作。长按进入多选，删除前确认移到回收站。
- 展开卡片后，右侧五角星可以标记重要，卡片以强调色显示。
- 当天已经开始的事务继续保留在页面中，前一天及更早的事务自动归档；归档内容可以在历史中查看和恢复。
- 支持多选操作，以及导出为日历可使用的 ICS 文件。

### 待办：清单与当天计划一起管理

- 提供「清单」「重复」「今天」「明天」「逾期」「重要」视图；各视图共用原事项，编辑、完成、重要标记和删除会同步。
- 一个清单可以连续添加多条事项：输入一条后按回车继续添加，最后点击「保存」。标题可以留空。
- 创建待办框时选择「统一时间」或「独立时间」，创建后固定类型。统一时间由框管理截止、提醒时间和频次；独立时间由每条事项分别设置，时间均可留空。
- 在「今天」或「明天」直接创建事项，无需框标题，时间只输入时分，默认在对应日期结束时截止。明天事项跨日后出现在今天，未完成事项超过截止时间后进入逾期；编辑不显示计划日期。
- 今天／明天按提醒时分排序，无提醒显示 `--` 并排在后面；清单事项显示来源，右侧星标切换重要状态。重要页保留框分组，当天独立事项按实际日期分组。
- 单次和重复提醒共用提醒时间，频次支持工作日、周末、天、周、月、年和自定义天数；统一时间只提醒整个框一次。重复页可跳过一次通知、恢复、关闭重复或确认删除。跳过不改节奏和截止，关闭重复保留原基准时间为单次提醒，过去的时间不会补发。
- 完成事项停止提醒，取消完成恢复未来提醒；统一框在全部事项完成后停止提醒。到截止时间、归档或删除后停止提醒。重复提醒不再自动复制事项。
- 支持完成进度、清单排序、显示已完成及「一键收起」；重复页不显示加号、显示已完成或一键收起。
- 返回时先收起键盘；有未保存内容时，再返回或取消会提示确认放弃。保存失败会保留填写内容。

### 日记：每天留下一篇记录

- 每天一篇日记，可通过月历或时间线浏览；月历提供农历和节假日信息。
- 支持心情、标签、收藏、模板和往年今日，方便补记和回看。首页空心爱心切换为红色实心后只显示收藏日记，再点恢复全部；摘要最多两行，标签显示 `#` 前缀。
- 日历内的「往年今日」显示历年同月同日的记录，也包含今年。往年有日记时，每天显示红色 `1`；日历与往年今日入口分别点击后消除各自红标。日记设置的「提醒往年今日」默认开启，通知权限允许时每天最多推送一条回顾通知。
- 与记忆共用正文编辑器，可插入图片、录音、文件和关联记录。
- 空标题显示「未命名」；标题和正文之间可添加深色标签，输入时固定带 `#`，可复用已有标签。标签旁的 × 只移除当前记录的标签，正文和其他记录保留。
- 长按进入多选删除；右上角更多菜单的「导出日记」进入导出选择，显示已选数量，支持再次点击「全选」取消全选。

### 记忆：按自己的结构收藏内容

- 首页分「工作」「生活」两个固定收纳入口，进入后再创建分类和记忆。旧版本已有记忆及回收内容升级后统一归入「工作」，原分类层级和正文保留。
- 创建分类与独立记忆，分类可以多层嵌套，分类和记忆可以混排。
- 提供列表和树状视图、路径导航、展开收起、置顶及排序；「排序」向左展开四项选择。
- 多选后的「移动到」可以逐层浏览目标分类，也可以在目标位置临时创建分类。
- 右上角更多菜单的「结构树」打开独立页面，以连续枝线连接节点，可以上下和左右滚动。分类名称用《》区分，节点展示前六个字符，超长显示 `...`；点击节点进入对应内容。在跳转入口返回时，可选择「返回树形图」恢复原位置，或「返回上级」离开树的浏览路径。
- 分类移动从长按多选发起；阅读某篇记忆后也可通过正文更多菜单的「移动到」调整位置，支持跨工作、生活移动。
- 右上角更多菜单的「导出」进入选择模式，自由勾选分类、记忆或全选，再选择导出内容。
- 日记和记忆多选均显示已选数量，删除前显示分类和记录数量；取消删除后保留勾选。日记导出不提供结构树选项。
- 分类内通过顶部搜索进入专属搜索页，默认当前分类及其下级，取消「仅在当前分类下」可查整个记忆模块；首页查工作与生活。查看结果后返回保留条件和位置。切换到其他模块后再进入记忆，会回到记忆首页。

### 编辑与搜索：找得到，也写得下

- 记录标题可选；正文支持标题层级、列表、勾选、引用、代码、加粗、斜体和局部文字格式。
- 支持章节折叠、正文目录、撤销重做、自动保存状态及历史版本恢复。
- 各模块顶部搜索按钮进入当前模块的专属搜索页面。日记支持仅收藏，时间表支持仅重要，两者均支持起止日期范围与历年某月某日；日期完整时可不输入关键词，起止当天均包含。待办提供全部、清单、今天、明天、逾期、重要、重复范围。
- 搜索覆盖标题、正文、标签、素材名称、事务备注与待办内容，显示命中内容和路径；可选择包含历史与归档。打开结果再返回，会保留关键词、筛选和滚动位置。
- 日期筛选勾选后展开，之后可独立收起。搜索时不完整日期自动清空，没有有效日期的条件自动取消；完整但无效的日期保留输入并提示修正。历史版本匹配可在结果中展开查看旧内容。

### 图片、录音与附件

- **图片**：正文预览或图片卡片，可查看、缩放、修改名称和重新绑定原文件。默认保存副本，也可选择引用原图；已有引用图片可以之后补存副本。
- **分类图片设置**：可以跟随上级，也可以独立设置。启用「强制下级」后，统一该分支的显示与保存规则，并为需要保存副本的已有图片补存；移动内容时重新计算有效设置。
- **失效引用处理**：补存失败会集中显示路径、图片名称和原因，保留原引用，可重新选择文件后重试。解除强制后恢复原独立配置，已有副本保留。
- **录音**：支持开始、暂停、继续、结束、后台录制、播放进度和倍速。
- **文件与关联记录**：手机文件建立外部引用，通过系统应用打开；也可插入整条记忆或整篇日记的关联卡片。

### 设置与文字导入

- 设置首页以三组无卡片边框的图标入口排列：使用偏好、数据管理、帮助与系统。
- 「常规 → 图片显示与保存」提供独立的默认图片设置页面。
- 回收站按时间表、待办、日记、记忆分页面，记忆再按工作和生活收纳；分类按原分支恢复，永久删除需要确认。日记删除后不显示撤销提示，可到日记回收站恢复。
- 「高级功能 → 文字导入事务」可把整理后的文本批量转为时间表事务或待办。提供可复制的 AI 提示词，粘贴结果后先预览、编辑和勾选，再确认导入。
- 图片、PDF 等原始资料由用户在外部工具中处理，时笺接收整理后的文字。App 内也提供使用说明和系统应用设置入口。

## 开始使用

1. 在 Android 8.0（API 26）及以上设备安装 APK，打开后即可使用，无需创建账号。
2. 选择对应模块，点击右下角「＋」创建内容。记忆先进入「工作」或「生活」，再点击「＋」选择创建分类或记忆。
3. 待办填写完成后点击「保存」；日记与记忆编辑器自动保存，并显示保存状态。
4. 需要跨设备保存内容时，到「设置 → 备份与恢复」生成完整备份，再保存到自己选择的位置。

当前源码的安装包构建位置为 `app/build/outputs/apk/debug/app-debug.apk`；构建方法见下方。

## 导出与备份

| 用途 | 格式与内容 |
| --- | --- |
| 单篇记忆或日记 | Markdown；有打包素材时使用 ZIP，也可选择 PDF |
| 分类、子树或多篇记录 | ZIP，保留分类目录、独立正文、素材和目录索引 |
| 结构概览 | 导出时可附结构树，每个所选顶层分类各生成一份 UTF-8 文本树 |
| 时间表 | ICS |
| 待办 | CSV |
| 全量迁移与恢复 | ZIP 完整备份，包含记录、分类、历史版本、回收站、事务、待办、设置和自存素材 |

导出默认包含时笺保存的图片与录音。引用图片和绑定文件由用户选择是否复制进本次导出或备份；无法读取的素材会列入缺失报告。普通导出用于阅读和分享，完整备份用于恢复 App 数据。

恢复完整备份会替换本机数据，操作前会自动保留一份本机恢复前备份。外部引用换设备后可能需要重新绑定。

本次升级到数据库 v12 时，仅一次性清理旧版待办框、事项、待办归档与回收站记录，并取消其提醒；时间表、日记、记忆及素材、标签和历史版本保留。旧备份恢复过滤旧版待办，新版备份完整保留新版待办。应用显示名为「时笺」，应用身份保持 `com.shijiannote.app`，可沿用原安装更新。

## 本地数据与权限

- **本地数据**：记录保存于设备的 Room 数据库，时笺保存的图片和录音存放在应用素材目录。数据库升级迁移既有内容。
- **引用原文件**：图片或附件采用引用方式时，依赖原文件及访问权限；原文件删除或权限失效后，需要重新绑定。
- **通知与提醒**：Android 13 及以上需要允许通知权限；精确提醒还取决于系统闹钟权限和设备后台设置。
- **录音**：需要麦克风权限，后台录音使用前台服务通知。
- **素材清理**：「清理未引用的图片与附件」清理的是时笺保存且没有被记录、回收站、历史版本、草稿或录音收件箱引用的副本。先显示可清理数量和大小，再确认清理；最近一天新增的文件暂时保留，不删除相册或绑定的原文件。

## 开发与构建

项目采用 Kotlin、Jetpack Compose、Room 和 WorkManager。源码中的当前配置：JDK 17、compileSdk / targetSdk 35、minSdk 26。

### Android Studio

1. 打开项目目录，使用 JDK 17。
2. 同步 Gradle；首次同步需要下载构建依赖。
3. 选择 Android 8.0 及以上的模拟器或手机，运行 `app`。

### 命令行

在项目根目录执行：

```powershell
.\gradlew.bat assembleDebug
```

安装包输出：

```text
app/build/outputs/apk/debug/app-debug.apk
```

单元测试与静态检查：

```powershell
.\gradlew.bat testDebugUnitTest lintDebug --max-workers=1
```

Android 设备回归测试包含数据库迁移、保存失败重试、导出与备份往返及界面操作，请使用专用模拟器或测试设备：

```powershell
.\gradlew.bat connectedDebugAndroidTest --max-workers=1
```

构建依赖缓存齐全时，可给命令添加 `--offline`。
