# 时笺笔记

一个本地优先的 Android 时间管理与记录应用，提供时间表、待办、日记、记忆和设置模块。所有内容保存于设备本地的 Room 数据库，无需账号或网络连接。

## 在 Android Studio 运行

1. 用 Android Studio 打开 `F:\ShiJianNote`。
2. 首次同步时，按提示下载 Gradle 与 Android 依赖。
3. 选择 Android 8.0（API 26）或更高版本的模拟器/手机，点击 Run。

项目使用 compileSdk 35、minSdk 26、JDK 17。

## 功能概览

### 时间表

- 新建带日期、可选精确时间、提前提醒和详情的事务；列表按开始时间排序。
- 点击事务展开或收起详情，展开箭头位于条目右侧。
- 提醒发送后，原“提前…提醒”文案会变为“已提醒”。
- 开始时间过去后，事务自动归档至历史；不设置持续时间，事务的开始就是提醒重点。
- 标题下方显示当天日期与星期；右上角齿轮菜单可进入历史或查看导出提示。

### 待办

- 待办首页固定提供浅绿色的“今天”和“明天”入口；可在待办设置中控制显示。“明天”开启时会同时开启“今天”。
- “今天”和“明天”内可新增事务、设置具体提醒时间及提前提醒。事务内容默认单行折叠，点击可展开查看或编辑。
- 每日迁移会在后台任务和下次启动时双重检查：当天事务归档为“今天 · 年.月.日”，原“明天”事务转入新的“今天”。
- 每个待办框包含摘要、连续添加的具体事项和可选截止日期；点击标题可独立展开或收起。待办框标题右侧的“收起”勾选可一次收起或展开全部待办框。
- 长按收起状态的待办框可上下拖动排序；新建待办框默认位于最底部。
- 设置截止日期的待办在日期过去后自动归档；历史中仍显示当时的“截止时间”。
- 右上角齿轮菜单可进入待办历史，并控制今天/明天入口。

### 历史与归档

- 时间表和待办的正常列表左滑可使用“更改 / 归档 / 删除”。
- 归档会移入历史；删除为永久删除，不显示二次确认。
- 历史列表左滑超过一半即永久删除，不提供更改或再次归档。
- 数据库升级会迁移既有数据，不会因加入历史功能而清空现有时间表或待办。

### 长按多选与排序

- 时间表、日记、记忆及历史列表支持长按进入多选；同级条目会显示勾选标记。
- 时间表与待办多选时，可选择白色“取消”、浅黄色“归档”或浅红色删除按钮；日记和记忆仅支持取消与永久删除。
- 多选状态下，右下角新增“＋”会隐藏，避免误触。
- 系统返回动作（手势导航边缘返回或三键导航返回键）会优先取消多选；在历史页则返回正常列表，在记忆分类内则返回分类列表。
- 今天/明天事务、记忆分类和分类内记忆：长按后松手会进入多选；继续按住并上下移动会退出多选、让卡片浮起，并以较慢速度调整位置。排序会保存在本地。
- 拖动期间会隐藏左滑操作层，避免露出“更改 / 归档 / 删除”的色块。

### 高级功能：文字导入事务

在“设置 → 高级功能 → 文字导入事务”中，可把外部 AI 整理后的文本批量转为时间表或待办。App 不会上传或解析原始图片、PDF、文件；这些资料需由用户交给支持相应识别能力的 AI 处理。

- 导入页提供可复制的提示词。提示词要求 AI 对无法读取的图片、PDF、扫描件或缺失附件明确输出 `issue`，不得猜测内容。
- 粘贴区接受 AI 完整回答，会从中提取逐行 JSON；前后解释文字、无效行和完全重复的条目会被忽略。
- 导入前会生成可勾选的预览草稿。点击草稿可展开编辑，修改后的标题、时间或备注会用于最终创建。
- 导入时间表时，AI 输出的 `start` 是默认时间；可手动填写时间，也可从已识别的 `start` / `end` 中选择。未给出提醒字段时默认不提醒。
- 导入待办时，AI 只需输出 `title` 和可选 `note`，不要求日期、时间或提醒；开始导入前可设定统一标题（默认“自主导入”）和可选截止日期。
- 缺少必要信息的条目不会自动导入：时间表必须补齐标题和有效时间，待办必须补齐标题。

### 日记与记忆

- 日记每日一篇，日期作为标题，并提供带已写日记标记的月历。
- 记忆支持创建分类及分类内条目；进入分类后，直接点击具体条目即可编辑，也可左滑使用更改/删除。
- 记忆分类和分类内条目均支持长按多选、全选、取消、删除与拖动排序。
- 日记和记忆删除后直接永久移除，不进入历史。

### 设置与关于

- “设置”提供通知入口和高级功能入口。
- “设置 → 关于 → 使用说明”会打开独立的移动端说明页，按 README 的时间表、待办、长按排序、导入、日记记忆和通知权限内容分章展示，并标出文档更新时间。
- “设置 → 关于 → 软件信息”会显示应用名“时笺笔记”、当前版本号和项目地址；项目地址 [https://github.com/RRRmazing/ShiJian-Note](https://github.com/RRRmazing/ShiJian-Note) 可点击，并通过系统默认浏览器打开。
- 时间表、日记、待办和记忆的右上角菜单均保留对应的历史、背景或导出入口；导出目前显示为后续功能提示。
