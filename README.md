# 时间笔记

一个本地优先的 Android 时间管理与记录应用，包含时间表、待办、日记、记忆四个模块。

## 在 Android Studio 运行

1. 用 Android Studio 打开 `F:\ShiJianNote`。
2. 首次同步时，按提示下载项目所需的 Gradle 与 Android 依赖。
3. 选择 Android 8.0（API 26）或以上的模拟器/手机，点击 Run。

项目使用 compileSdk 35、minSdk 26、JDK 17。

## 已实现功能

- 时间表：顶部显示今天日期；任务按时间由近到远；可展开查看详情；提醒文案自动隐藏值为 0 的天、小时或分钟。
- 待办：可建立任意数量的待办框；摘要与具体任务分开；可选截止日期；连续添加与勾选完成。
- 日记：每日一篇；日期自动作为标题；列表预览；带已有日记日期标记的月历。
- 记忆：分类与分类内具体条目。

所有数据保存在设备本地的 Room 数据库中。首次运行 Android 13 以上系统时，请在系统设置中允许通知；如果系统要求精确闹钟权限，也请允许，以获得最准确的时间表提醒。
